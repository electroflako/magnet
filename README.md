# MAGNET – Estudio Creativo Digital

Landing page de diseño vanguardista para estudio creativo independiente.

- **Stack:** React 19, Tailwind CSS 4, Framer Motion, Lenis Smooth Scroll, Lucide.
- **Efectos:** Cursor magnético customizado, animaciones split-text en scroll, tipografía editorial Syne & Instrument Serif, acordeón interactivo de servicios.
- Desplegado 24/7 en GitHub Pages.
